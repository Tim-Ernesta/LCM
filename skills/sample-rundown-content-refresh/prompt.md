STEP 1 - READ THE DE
Pull every row. Save a full backup to backup_<YYYYMMDD>.json before changing anything. Never delete rows, never change the primary keys, never touch other fields.

STEP 2 - PICK TARGETS (colorways)
A colorway is a target if (a) its review fields are blank, (b) its image field is blank or the URL is broken (non-200 or not an image content-type), or (c) it has weaker content: a review quote longer than 230 characters, not 5-star, or clearly not about the rug; or an image that fails the step 3 quality bar. IMPORTANT: there is NO minimum review length (short reviews are fine); the maximum is 230 characters because the email prints the quote in full. Incentivized reviews are fine and are NOT weak; a review from a different colorway of the same style (ReviewMatch = Style) is NOT weak either. Content that passes all checks is left exactly as it is; never swap an acceptable review for another acceptable one.

STEP 3 - FIND CANDIDATES (per target colorway, exact colorway only)
- Review: 5-star only, not deleted/archived/blocklisted, incentivized allowed (set ReviewIncentivized to Yes/No accurately), service-oriented reviews allowed, no minimum length, positive and about the purchase of the rug, no profanity, no complaints, no personal data (emails, phone numbers, full last names), and it must NOT mention design assistants / staff by name (e.g. a named consultant) and must not be written by an Ernesta employee or executive. Prefer a whole review of 230 characters or fewer. If the best review is longer, make an excerpt of at most 230 characters from whole, verbatim sentences of the original (never reword, never cut mid-sentence). What to cut: drop only preamble and context (backstory, shopping journey, "I wasn't sure what to expect", what they ordered) and secondary detail. What to keep: the actual opinion of the rug (the sentence(s) with the verdict, praise, quality, look, feel, fit, and a closing recommendation or repeat-purchase line). Never drop the review's core verdict to keep the backstory. Skipped middle sentences are fine; keep the kept sentences in original order. Verify in code that every kept sentence appears verbatim in the original and that the result is 230 characters or fewer, and set ReviewExcerpt Yes; otherwise ReviewExcerpt No. If no excerpt can keep the real opinion within 230 characters, choose a different review. Decode HTML entities, collapse newlines to spaces. Prefer the most recent qualifying review. Set ReviewName to the reviewer name as in Yotpo, ReviewId to the Yotpo review ID, ReviewColor to the colorway, ReviewMatch Exact, UpdatedDate to today.
- UGC image: from a 5-star photo review or the social field for the exact colorway; rug clearly visible and in focus; URL returns 200; short side at least 800px (check with Pillow; pip install pillow --break-system-packages if needed); not a screenshot, collage, packaging shot, or a photo with a face as the main subject; no text overlays or watermarks. View each candidate image (Read tool on the downloaded file) before choosing it. Prefer in-room photos. If chosen, set ImageUrl, ImageType UGC, ImageMatch Exact, ImageColor, UGCBy, UGCReviewId. If none passes, leave the fields as they are (historically the PDP-image colorways have no exact-colorway photo reviews, so expect few or no image changes).
- Never use content from a different style.
