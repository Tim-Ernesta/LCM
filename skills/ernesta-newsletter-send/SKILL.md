## Order of work

1. **Name and dates.** `Newsletter_<NNN>_<Topic>_<MMDDYY>`: NNN from the Notion tracker ticket title, e.g. "(216)"; MMDDYY is the send date Tim gives (not the tracker's due date). Confirm timing (test list entry time + wait). Use the same name for the audience DE, query and journey; emails are `<name>_VA` / `_VB`; images `NL<NNN>_<Topic>_<MMDDYY>_<slot>.jpg`.
2. **Emails.** Clone the newest send's modules (offer, recs + review, collections, preheader AMPscript), or the template Tim names. Images go to Content Builder (`POST /asset/v1/content/assets`, assetType jpg id 23, folder id 27275, `file` base64) so they get image.m.ernesta.com URLs. Replacing an image with `PATCH ... {file}` keeps the URL. Keep the hidden body preheader div empty so the Content Builder preheader view (with the 15% AMPscript variant) shows. HTML must be ASCII (entities). **Dark mode stack is required** (Memory process page): `<body class="body">`, color-scheme meta `light only`, the head CSS blend/dm-promo rules, and `<div class="gmail-blend-screen">` around every white-on-photo copy block (review overlay, white hero header copy). Copy the head and body tag from Tastemakers_CamilleStyles_102026_VB, not from NL214 (it is missing the CSS). Verify with `scripts/darkmode_check.py <asset name>`; all 9 checks must pass for VA and VB. **Preview-text hack is required** (without it Gmail shows body copy after the preheader): right after `<body class="body">` put the block in `references/preview_hack_block.html` (empty hidden div + 90 x `&#xFEFF;&#x34F;` filler div); never rely on the editorial template's short hidden div. **Links are required on every headline, both logos, every image and every subhead**, with styling unchanged (anchor repeats the text colour, no underline, `border:0`; block-width anchor for logos, plain inline for text); prove no visual change with a pixel diff of before/after recipient previews; `journey_checklist.py` item L checks coverage. **The SMS opt-in line ("Text ERNESTA to 96754 to stay connected") is plain text: never wrap it in an `sms:` link (broken); it is the one exception to the link-everything rule.** **Standard footer (Tim, 2026-10-27): every NL send uses `references/standard_footer.html` (also on the Memory page "Standard footer for every Ernesta NL send"), not the editorial template footer. The address is wrapped in `<span class="addr">` plus an href-less anchor with colour `#f8f6f3` and the head CSS replaces the template's `a[x-apple-data-detectors]` rule so Gmail, Apple Mail, Outlook and Samsung never auto-link it blue. Re-render previews and confirm a pixel-identical diff.** **Send-readiness is required** (Subscriber Preview fails without it): footer Update Profile link `%%profile_center_url%%`, `<custom name="opencounter" type="tracking"/>` before `</body>`, unsub link, address merge fields, and the text view set to generate from html (`views.text.generateFrom` and `data.email.options.generateFrom` = html). Verify with `scripts/send_readiness_check.py <asset names>` (no validation API exists; Tim's Subscriber Preview is the final test). Email assets: assetType 208 htmlemail, folder 25879; they get a `legacyData.legacyId` the journey needs.
3. **Data.** Audience DE (sendable on `Id` / `_SubscriberKey`, schema of the newest send), `_Recs_ByStyle` = newest send's table, `_RevUgc` = newest send's table. **Featured styles** (any swatch shown in the email) must be removed from recs, review and static fallback: `scripts/featured_fix.py`. Population query: clone the newest send's SQL (it blanks codes for rug buyers and sets PURCHASED), replace the name, create via `POST /automation/v1/queries` (category 25873, target = the audience DE, overwrite), run with `POST /automation/v1/queries/{id}/actions/start/`; ~35 min. Edit an existing query with PATCH, not PUT. Do not create queries that overwrite shared scratch tables (the classifier blocks it): compute audits read-only.
4. **Journey.** Clone the newest journey JSON, replace names/event key/DE id/field ids/email ids, strip `triggeredSendId/Key`, new activity ids. First create the event definition (`POST /interaction/v1/eventDefinitions`), then `POST /interaction/v1/interactions`. Description must be about 200 characters or less (longer returns error 30000) and follows: topic + off-ramps + "Test list 0730, rest after 60 min wait. 50-50 VA vs VB ... Send YYYY-MM-DD 0830 ET". The dynamic preheader AMPscript also goes into every email activity's `triggeredSend.preHeader`. After any email edit, run `scripts/refresh_email_activities.py <journey>` (checklist item 13; draft journeys only). To edit a draft journey use `PUT /interaction/v1/interactions` with the body exactly as fetched (keep `modifiedDate` or you get "another user modified"). Leave it Draft: Tim publishes. A journey PUT can make Builder create a replacement event definition + entry automation: after every PUT verify the trigger's eventDefinitionKey and delete orphans (event definition by REST DELETE; automation by SOAP DeleteRequest, REST returns 404); journey_checklist.py item 14b checks this.
5. **QA before hand-off.** Send-readiness check (`scripts/send_readiness_check.py`), journey checklist (`scripts/journey_checklist.py`, items in `references/journey_checklist.md`; standard for every NL journey), dark-mode check (`scripts/darkmode_check.py`), stock check (`scripts/stock_check_sql.py`, run in Snowflake, 0 rows = pass), featured styles, duplicates, reviews not in grid, codes on ineligible, seeds, net audience (`scripts/net_audience.py`). On send morning: re-pull stock, compare recent Shopify rug buyers against coded contacts, re-run the recs.
6. **Real recipient previews** of the live emails: `scripts/render_previews.py <name> <outdir> <featured>`. Static-fallback or sample-data renders do not count. Mask codes. Send screenshots with SendUserFile from the scratchpad.
7. **Slack post** in the exact Memory format, written out in chat. Audience table = net audience (holdout, seeds, off-ramps), rows Lead / Sample Customers / Consumer Rug Customers / Trade / TOTAL.
8. **Save corrections to Memory** as Tim gives them.

## Gotchas learned
- Image hosts must be allowed in the environment: image.m.ernesta.com, res.cloudinary.com, cdn.shopify.com, www.ernestarugs.com, air-prod.imgix.net.
- CDN can serve the old image for a few seconds after a PATCH: wait before screenshots.
- The Python-`-I` flag drops the script dir from the path; use PYTHONPATH.
- `%` formatting breaks on AMPscript's `%%`: use string replace.
- Content search (`like` on content) in Content Builder is fuzzy; fetch the HTML and grep instead.
